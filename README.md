## 어려웠던 점 3가지와 해결

1. **GitHub Pages 배포 후 상세 페이지 접속 시 404 에러 발생**
* *해결:* 파일들이 루트 디렉토리(최상위 폴더)가 아닌 다른 곳에 있거나 파일명 대소문자가 일치하지 않아 발생한 문제임을 파악하고, 모든 파일을 루트에 올바른 소문자 명칭으로 재배치하여 해결함.


2. **다섯 개의 영화에 각각 다른 상세 내용을 개별 파일로 연결하기**
* *해결:* 단일 상세 페이지 대신 영화별로 `detail1.html`부터 `detail5.html`까지 개별 파일을 만들고, 메인 페이지의 각 영화 카드 링크를 각각 알맞은 번호의 파일로 정확히 매칭시킴.


3. **HTML 시멘틱 구조 설계와 CSS 스타일링 배치**
* *해결:* MDN 문서를 참고하여 박스 모델과 레이아웃 태그의 구조를 이해하고, 메인 보드와 상세 페이지의 디자인 통일성을 맞춤.
